# Shared-screen note font

Klee One SemiBold supplies the Japanese handwriting used by native screen notes.
The unmodified font is embedded in the macOS executable; it is not installed into
the user's system. If CoreText cannot load it, the renderer uses a local Japanese
font and then the system font. No runtime download is needed.
