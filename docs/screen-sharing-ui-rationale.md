# 画面共有UIの判断記録

2026-09-12。対象はメイン画面と補助ウィンドウの共有設定。実アプリの公式資料と画像を確認し、ユーザーの指定を優先して整理した。

## 各要素の理由

| 要素 | ユーザーの目的 | 位置・形・動作の理由 |
| --- | --- | --- |
| 戻る | 画面／カメラの選択に戻る | 見出し直前の実SVGアイコンのみ。ユーザー指定の折り返し矢印`Undo2`を使用し、aria-labelとツールチップは「戻る」／Back。一般的なUndoとの連想は、見出し横のナビゲーション位置とラベルで区別する。 |
| 見出し | 現在の設定対象を把握する | 戻るアイコンと同じ行に「画面共有」／「カメラ共有」。設定内容に対応する名称を保つ。 |
| 閉じる | 設定表示を閉じる | メインの見出し右端にX。戻ると役割を分け、名前とツールチップを付ける。設定を閉じても共有停止にはしない。補助ウィンドウは既存のウィンドウ閉じる操作を使う。 |
| 画面全体／ウィンドウ／範囲タブ | 共有範囲を切り替える | 内容の上に実際のタブを配置。選択状態は下線で表示。矢印・Home・Endはフォーカス移動のみ、クリック・Enter・Spaceで確定。移動だけで許可要求や共有停止を起こさない。 |
| 共有元一覧と更新 | 具体的な画面・ウィンドウを選ぶ | 画面全体・ウィンドウのタブ内に一覧と更新アイコンをまとめる。範囲では一覧を出さず、描き始めたディスプレイを採用する。共有中・処理中はモード変更・カメラへの切替を無効にする。 |
| 範囲選択 | 送る領域を決める | 範囲タブから「共有を開始」で最初の枠を描く。選択前に画像を取得・送信せず、Escなら停止状態へ戻る。選択後はデスクトップ上の枠を移動・リサイズでき、確定した範囲を自動で次の共有へ反映する。別の選択ボタンやディスプレイ一覧は置かない。選択後の寸法は確認用に残す。 |
| プレビュー | 自分に見える共有プレビューを調整する | 表示設定として配置。共有開始や停止と独立し、相手へ渡した画像と同じバイト列を表示する。 |
| 更新間隔 | サンプリング頻度を決める | ラベル、スライダー、現在値をまとめる。既存のトークン消費説明を同じ場所に置く。 |
| 指し示し | 対応する共有でポインターを使う | 画面全体のみ表示し、カメラ・ウィンドウ・範囲では非表示。機能制約は動作で保ち、ユーザーが不要とした説明文は表示しない。 |
| 開始／停止／キャンセル | 共有の実行を明示する | 設定の最後に主要な塗りボタンを一つ置く。共有中は停止、待機中はキャンセルに変わる。設定を開くだけでは共有しない。 |
| エラー・権限案内 | 失敗から復帰する | 実際に問題がある場合だけ、操作に近い場所へ既存の案内を表示。エラー時に勝手に広い範囲へ切り替えない。 |
| 処理・共有状態 | 待機と共有結果を判断する | 見出し付近の小さな状態表示を利用。競合する操作を無効にし、送信成功後だけプレビューを更新する。 |
| 旧ネイティブとの互換性 | 開発途中でも画面全体とカメラを使える | 新機能対応をソースの明示的な`kind`で確認。未対応のメイン画面ではウィンドウ・範囲タブを無効にし、「実行中のアプリではまだ利用できません」という短いツールチップに限定。補助ウィンドウは旧形式へ安全に戻し、未対応タブを出さない。 |
| 説明文の量 | 設定画面を簡潔に保つ | ユーザー指定で「ポインター表示は画面全体の共有時に利用できます」「画面上をドラッグして選択。Escでキャンセル。」「共有を開始すると共有する範囲をドラッグして選べます」「選ぶまでは共有されません」および英語版を削除。別の説明段落へ置き換えない。ドラッグ・Escの動作は残す。 |

## 整えた見た目

- 戻るアイコンは通常時を控えめにし、ホバー・フォーカス時に反応を示す。
- タブの区切りと選択色は既存のテーマ変数を使用する。
- タブ内容の間隔はgridで管理し、従来の一覧下マージンとの二重余白を取り除く。
- 範囲の選択・選び直しボタンとディスプレイ一覧を省き、開始／停止に操作をまとめる。
- 変更は共有UIに限定し、ターミナルや全体のCSSへ広げない。

## 動作とアクセシビリティの確認

- tablist／tab／tabpanel、aria-selected、フォーカス移動をテスト。未対応タブへフォーカスを移さない。
- 戻るはアイコンのみで、見出しの直前にあることを両画面でテスト。SVG自体はaria-hiddenにする。戻った後は選択メニューの最初の有効なボタンへフォーカスを移し、キーボード操作を継続できることもテストする。
- 共有中はモード切替を無効にし、範囲の移動・リサイズだけを許可する。最初の描画取消・停止後の古い選択結果では送信を始めない。
- 枠の操作中は新しいキャプチャを止め、旧領域の送信済みリクエストが完了してから新しい範囲の共有リースへ移る。送信がタイムアウトした場合は停止する。Escの取消は元の領域で再開する。
- ウィンドウ候補を明示的なwindow種別で絞る。制限付き共有は返却フレームのselectionKindとsourceIdを確認してから送信・プレビューへ渡す。
- 対応判定は空一覧やカメラへの切替でも維持する。HMRで古いrefに判定値がない場合もfalseとして扱い、再読込なしで閉じた状態を保つ。
- 旧ネイティブでも画面全体・カメラを阻害しない回帰テストを追加。

検証: TypeScript、Biome、共有関連104テストが成功。説明文削除・戻る後のフォーカス移動の修正後、影響するUIの43テストも成功。実アプリの再起動・ネイティブ有効化はこのUI作業では行っていない。
